**Software you own.**

Pouwel Technologies builds software that runs on your own machine, minds its
own business, and keeps working forever.

## The rules

Everything published here is:

- **Free.** No subscriptions, no paid tiers, no upsells.
- **Private.** Nothing you do in it leaves your machine. No telemetry, no
  analytics, no tracking, nobody collecting anything about you.
- **Local.** It runs entirely on your own machine. No accounts, no sign-ups,
  no API keys, and no server it depends on to function.
- **Open source.** The source is the product, released under GPL-3.0.
- **Forever.** No expiry, and nothing that stops working because a service
  somewhere got switched off.

Open source is how you check the other four. Anyone can read the code and
confirm that nothing is leaving the machine.
